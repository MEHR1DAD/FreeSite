# ساخت وب‌سایت مدرن با FreeSite و میزبانی ابری رایگان

پروژه **FreeSite** با این هدف متولد شده است تا هر توسعه‌دهنده، فریلنسر، صاحب کسب‌وکار یا طراح بتواند بدون دغدغه هزینه‌های دلاری هاست و سرور، وبسایتی فوق‌العاده سریع و استاندارد داشته باشد.

## چرا معماری Jamstack و استاتیک؟

وب‌سایت‌های استاتیک مدرن دارای چندین مزیت کلیدی هستند:

1. **سرعت بارگذاری شگفت‌انگیز**: تمام صفحات از قبل بیلد شده و روی شبکه جهانی CDN کلودفلر قرار می‌گیرند.
2. **امنیت مطلق**: عدم وجود دیتابیس مستقیم و آسیب‌پذیری‌های رایج CMSهای سنتی مانند وردپرس.
3. **هزینه صفر**: پلان رایگان Cloudflare Pages پهنای باند و تعداد درخواست‌های نامحدود ارائه می‌دهد.
4. **پنل مدیریت متصل به گیت**: تمامی تغییرات شما مستقیماً در قالب کامیت‌های گیت در ریپازیتوری ذخیره می‌شوند.

```bash
# اجرای لوکال پروژه
git clone https://github.com/MEHR1DAD/FreeSite.git
cd FreeSite
npm install
npm run dev
```

## تغییر تم با یک کلیک

در این موتور، ۱۴ تم متنوع و خیره‌کننده شخصی و شرکتی آماده شده است که تنها با ویرایش یک خط در پنل ادمین یا فایل `site.json` می‌توانید تمام ظاهر سایت را دگرگون کنید!
