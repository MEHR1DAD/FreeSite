# Unleash the Power of Edge-Rendered Websites with FreeSite

FreeSite combines the cutting-edge capabilities of **Astro SSG**, **Tailwind CSS**, and **Sveltia CMS** to deliver a zero-friction website creation experience.

## Key Advantages

- **Zero Hosting Costs**: Host on Cloudflare Pages forever with infinite scalability.
- **Pure Static Performance**: Ships zero client-side JavaScript by default for blazing fast First Contentful Paint.
- **Git-Backed Content Management**: Sveltia CMS commits every content change directly to your GitHub repository.
- **14 Pre-built Themes**: Switch between personal portfolio, resume, cyber, terminal, or corporate layouts seamlessly.

```javascript
// Switching themes is as simple as:
{
  "theme": "terminal-tech"
}
```
